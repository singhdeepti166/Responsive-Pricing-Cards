# 🎀 Responsive Pricing Cards

A modern, responsive pricing section featuring three subscription plans with an interactive Monthly/Yearly billing toggle.

Built as part of my **InternCircle Full Stack Web Development Internship**.

## ✨ Features

- Three pricing plans: Starter, Pro and Team
- Interactive Monthly and Yearly billing toggle
- Approximately 20% savings on yearly billing
- Popular and Best Value badges
- Cute 🎀 decorative card elements
- Smooth hover animations and transitions
- Responsive layout for mobile, tablet and desktop
- Accessible buttons with ARIA attributes
- Keyboard focus indicators
- Reduced-motion support

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 💳 Pricing Plans

| Plan | Monthly | Yearly / Month |
|---|---:|---:|
| Starter | ₹199 | ₹159 |
| Pro | ₹499 | ₹399 |
| Team | ₹999 | ₹799 |

*Yearly prices are effective monthly rates, billed annually.*

## 🚀 How to Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
